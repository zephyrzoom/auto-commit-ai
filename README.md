# Git 同步工具

一个Windows桌面GUI程序，用于自动同步Git仓库的提交记录到用户自己的分支。

## 功能特性

- 🔄 **自动同步**：每天定时获取远程仓库的提交记录
- 👤 **自定义作者**：将提交作者修改为你的信息
- 🕐 **保留时间**：保持原始提交时间不变
- 🔧 **强制覆盖**：每次同步强制覆盖目标分支
- 🔒 **密码加密**：密码使用加密存储，安全可靠
- 📊 **日志记录**：实时显示同步过程和日志

## 安装

### 1. 安装Python 3.10+

确保已安装Python 3.10或更高版本。

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

依赖包括：
- PyQt6：GUI界面框架
- GitPython：Git操作库
- APScheduler：定时任务调度
- cryptography：密码加密

## 使用方法

### 1. 启动程序

```bash
python main.py
```

### 2. 配置程序

首次启动时，点击"配置"按钮填写以下信息：

- **仓库URL**：要同步的Git仓库地址（必填）
- **用户名**：Git账号用户名（必填）
- **密码**：Git账号密码（必填）
- **源分支**：要同步的原始分支（默认：main）
- **目标分支**：同步后的目标分支（默认：my-sync-branch）
- **您的姓名**：显示为提交作者的名字（必填）
- **您的邮箱**：显示为提交作者的邮箱（必填）
- **每日同步时间**：每天自动同步的时间（默认：00:00）

### 3. 立即同步

配置完成后，点击"立即同步"按钮即可立即执行同步。

### 4. 查看日志

在"日志"区域可以查看详细的同步过程信息。

### 5. 定时同步

程序会在配置的时间自动执行同步，无需手动操作。

## 工作原理

1. **获取提交**：从源分支获取所有提交记录
2. **创建分支**：在目标分支上工作
3. **重新提交**：逐个重新提交，修改作者信息但保留原始时间
4. **强制推送**：使用force push更新远程目标分支

## 配置说明

### 强制覆盖模式

程序采用强制覆盖模式，每次同步前会重置目标分支到源分支状态，确保完全同步。

### 增量同步

程序会记录上次同步的commit hash，下次同步时只获取新的提交。

## 注意事项

- 确保Git仓库账号有推送权限
- 目标分支会被强制覆盖，请勿在目标分支上保存重要修改
- 密码已加密存储，但仍需注意安全
- 首次同步可能需要较长时间（取决于提交数量）

## 打包为exe

使用PyInstaller打包为Windows可执行文件：

```bash
pip install pyinstaller
pyinstaller --windowed --onefile --name="Git同步工具" main.py
```

生成的exe文件在 `dist` 目录中。

## 故障排查

### 同步失败
- 检查网络连接
- 验证用户名密码是否正确
- 确认仓库URL格式正确
- 检查是否有推送权限

### 定时任务不执行
- 确保程序保持运行
- 检查系统时间和时区设置
- 查看日志中的错误信息

### 分支冲突
- 目标分支将被强制覆盖，无需处理冲突
- 如需保留本地修改，请切换到其他分支
